# STUDYWISE — Smart Study Management and Planning System

A C++-based academic management project developed as part of the **Problem-Based Learning (PBL)** curriculum at Graphic Era University.

StudyWise aims to help students organize their academic subjects, manage syllabus topics, track study progress, and eventually plan their preparation more effectively using data structures and algorithms.

## 📌 Project Overview

Students often manage their academic syllabus, study resources, and exam preparation across multiple applications and folders. This can make it difficult to organize topics, track progress, and decide what to study next.

**StudyWise** is being developed to bring these academic activities into one organized platform. The project combines a web-based user interface with a C++ backend, applying Object-Oriented Programming (OOP) and Data Structures and Algorithms (DSA).

## 🎯 Project Objectives

- Organize academic subjects and their associated topics.
- Maintain syllabus information, difficulty levels, and estimated study hours.
- Track topic completion and study progress.
- Apply C++ OOP principles to create structured and maintainable code.
- Implement searching, sorting, and other relevant DSA techniques.
- Develop a smart study planner that recommends topics according to academic priorities.
- Provide a centralized system for managing study materials and their file locations.

## ✨ Current Features — Phase II Prototype

- **Dashboard:** Displays an overview of subjects, topics, study hours, and progress.
- **Subject Management:** Create and organize subjects with course codes and semester information.
- **Topic Management:** Add, edit, and delete topics associated with subjects.
- **Progress Tracking:** Mark topics as in progress or completed.
- **Search and Sorting:** Search academic records and explore topics using implemented searching and sorting functionality.
- **C++ Backend:** Processes application requests through a REST API.
- **JSON Persistence:** Stores application records locally so data can persist across backend restarts.
- **Web Interface:** React-based frontend with a responsive, dark-themed interface.

*The project is under active development. Features and implementation details may change as subsequent PBL stages are completed.*

## 🧠 OOP and DSA Concepts

The project is designed to demonstrate practical applications of:

- **Classes and Objects:** Representing subjects and topics.
- **Encapsulation:** Protecting data and validating inputs through class methods.
- **Data Structures:** Managing academic records using suitable structures.
- **Searching Algorithms:** Locating subjects and topics efficiently.
- **Sorting Algorithms:** Organizing records according to selected criteria.
- **Priority-Based Planning:** A planned extension for ranking study topics based on urgency and academic importance.

## 🚀 Planned Enhancements

The following capabilities are intended for subsequent development stages:

- Smart study planning based on exam dates, remaining syllabus, difficulty, and available study time.
- Priority calculation and a custom Max-Heap implementation.
- Study material organization with file paths and resource access.
- PDF and document management.
- A daily study schedule with topic recommendations.
- Further testing, integration, and refinement of the application.
